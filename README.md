# Tactic

A 2D side-view prototype of a turn-based combat system developed in Unity.

## Gameplay Demo

[Watch the gameplay video on YouTube](https://youtu.be/zhFflRF5lWw)

## Technologies

* **Unity**
* **C#**
* **A* Pathfinding** — pathfinding for units
* **Addressables** — asset management and loading

## Project Overview

The project explores the implementation of turn-based combat mechanics in a 2D environment, with a focus on unit movement and pathfinding.
